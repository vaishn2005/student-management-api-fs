# Student Management System

A full-stack Student Management System developed using React, Node.js, Express.js, and MongoDB.

## Features

- Add students
- View students
- Delete students
- Store student marks
- Student performance analysis
- Study plan generation
- REST API for student management

## Technologies Used

- React.js
- JavaScript
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- HTML
- CSS

## Project Overview

This project is designed to manage student information and their academic performance.

The frontend is built with React and provides the user interface for managing students.

The backend is built using Node.js and Express.js and provides REST APIs for creating, viewing, and deleting student records.

MongoDB is used to store the student information and marks.

## Student Details

The system stores:

- Student Name
- Course
- JavaScript Marks
- Python Marks
- Java Marks
- DSA Marks
